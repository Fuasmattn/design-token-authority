# Storybook fixture

`storybook-static/index.json` was recorded from a real `storybook build` (Storybook 10.6.1, `@storybook/html-vite`) of a tiny project: Button (Primary, Outline, Experimental tagged `skip-dta-diff`), Card (Default) and one MDX docs page. `@dta/visual-diff` (`readStorybookIndex`) and the CLI (`dta diff --list`) test against it.
