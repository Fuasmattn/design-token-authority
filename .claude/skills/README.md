# Vendored skills

The skills in this folder are copied from [mattpocock/skills](https://github.com/mattpocock/skills) at commit `49dd158`, under the MIT License (see `LICENSE-mattpocock-skills`).

| Skill | Use in this repo |
|---|---|
| `grill-with-docs` | Grill a concept against the existing docs and `AGENTS.md` |
| `to-spec` | Turn a grilled concept into a spec |
| `to-tickets` | Break a spec into tickets in `docs/tickets/` |
| `implement-spec` | Implement a spec ticket by ticket |
| `tdd` | Test-driven implementation |
| `handoff` | Hand context over between sessions (phone ↔ Mac) |
| `grilling`, `domain-modeling` | Dependencies of `grill-with-docs` |
| `code-review`, `codebase-design` | Dependencies of `implement-spec` and `tdd` |

To update, re-copy from upstream and bump the commit hash above.
