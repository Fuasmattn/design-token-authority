Components use only the **semantic** tokens; each aliases a primitive per theme. The swatches use the built CSS variables.

- **Text reaches 7:1** in both themes (a test checks). The one exception: the redline label, `signal-fg` on `signal-bg` (5.7:1). Text on `signal-bg` is always `signal-fg`, never white.
- **`signal` never means an error.** Results use the `status-*` group: [Status colours](/design-system/status-colours/).
- **Decorative only, not for text:** `ink-600`, `graphite-400`, `paper-500`, and the `well-*` group (the landing page's gravity well).
- `terminal-*` belong to the terminal, which is dark in both themes.
