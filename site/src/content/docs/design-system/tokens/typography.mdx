Instrument Sans for everything you read, condensed (`font-stretch: 85%`) for display sizes. Martian Mono for anything a machine also reads: commands, token names, file paths, meta labels and redline labels. Both are self-hosted.

Each style is four or five tokens (`type.<style>.family`, `.size`, `.line-height`, `.weight`, sometimes `.letter-spacing`). DTA writes font sizes without a unit, so CSS multiplies them: `calc(var(--type-body-size) * 1px)`.
