- **Instrument Sans** for everything you read; condensed (`font-stretch: 85%`) for display sizes.
- **Martian Mono** for what a machine also reads: commands, token names, file paths, meta and redline labels.

Sizes are unitless: `calc(var(--type-body-size) * 1px)`.
