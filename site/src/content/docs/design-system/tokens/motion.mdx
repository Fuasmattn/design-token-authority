`fast` for small changes in place, `base` for most transitions, `slow` for larger moves; `highlight` is the fade of a changed value. How to use them: [Motion](/design-system/motion/).

## Durations

<MotionTokens kind="duration" />

## Easings

`standard` for things that stay and move, `enter` for things that appear, `exit` for things that leave. Never a bounce.

<MotionTokens kind="ease" />

## In CSS

```css
.dta-detail[open] {
  transition: transform var(--motion-duration-slow) var(--motion-ease-enter);
}
```

Components use these variables only; a literal duration or easing fails a test. Endless decorative loops (the gravity well, the terminal cursor) keep their own periods.
