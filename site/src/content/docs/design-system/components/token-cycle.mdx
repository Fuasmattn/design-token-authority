A word under a redline whose tag names the type token styling it. It cycles through a few styles on click and every two seconds. Used once, in the landing page's hero.

<Examples component="token-cycle" />

## Guidelines

- One per page. Three or four styles: weights in the font's range (400–700) and italic; the token names are illustrative.
- Decorative: the word stays plain text, so a heading reads as written. Hover pauses it.
- Weight and redline change over `motion.duration.slow`, the tag over `base`. Reduced motion: no automatic change, no animation.
- Stories set `autoplay={false}` for stable screenshots.
