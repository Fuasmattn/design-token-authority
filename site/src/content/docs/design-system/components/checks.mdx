The checks of a pull request as flat rows on `bg-surface`, with the approve action.

<Examples component="checks" />

## Guidelines

- Each row: a marker, the check's name and its status word, in the [status colours](/design-system/status-colours/): `passed`, `passed with warnings`, `failed`.
- `changes to review` is not a problem: it stays `signal` (dot `signal-bg`, word `signal-text`), never a warning.
- `pending` stays in the ink (`fg-subtle` dot, `fg-muted` word).
- The approve action is a label of what a person does (`action-text` with `action-fg`), not a working button.
