## Guidelines

- Header strip in mono meta: "TERMINAL" and "SAME INPUT · SAME OUTPUT".
- Prompt and changes in `terminal-prompt`, passes in `terminal-success`, secondary lines in `terminal-muted`, the rest `terminal-fg`; all 7:1 on `terminal-bg`.
- `terminal-success` is the terminal's own token, not a [status colour](/design-system/status-colours/): the terminal is dark in both themes. A pass is a word ("passed"), never colour alone.
- Output is copied from a real run; never invent numbers.
- The cursor blinks; it stops under reduced motion.
