The [playground](/playground/)'s input once something is loaded: one line saying what is loaded, with "Replace files" and "Paste JSON instead".

## When to use

- Above a workspace whose content the visitor chose, to say what is shown and offer to change it.
- Not before anything is loaded: then the [Token input](/design-system/components/token-input/) takes the page.

<Examples component="source-bar" />

## Guidelines

- One flat line: `bg-surface`, `stroke-hairline` in `border-default`, `radius-md`. It wraps when narrow (actions under the label), never scrolls sideways; file names break between segments ([Token path](/design-system/components/token-path/)).
- "Loaded" and the detail in mono `fg-subtle` / `fg-muted`; what is loaded in label type. Imports use the words of `dta pull --from-file`.
- "Replace files" is an outline [Button](/design-system/components/button/) (several files at once); "Paste JSON instead" is a link button with `aria-expanded`. Both 44 px tall.
- A status region that also reads out the file names; after a new read, focus moves to it.
- Reads files with the Token input's `readFiles`, so both inputs read the same way.
- **Motion:** view-transition part `dta-source`, shared with the Token input's drop area, so loading collapses the drop area into the bar ([Motion](/design-system/motion/)).
