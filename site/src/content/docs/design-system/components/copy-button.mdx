Copies a text and says so: every output file and the generated config in the [playground](/playground/).

## When to use

- Next to a file or config the visitor may want in their own editor; pair it with Download.
- Not for commands: the command chip copies itself.

<Examples component="copy-button" />

## Guidelines

- It is the [Button](/design-system/components/button/): quiet on a row, outline where it stands alone.
- After copying it reads "Copied" for 1.6 s after the pass dot; when the browser refuses, "Not copied" after the error square. Shape and word, never colour alone.
- All labels share one grid cell, so the width never changes.
- A polite live region announces the result. When the label doesn't say what is copied, the accessible name does: "Copy output/css/base.css".
