"Take it to the CLI": in the [playground](/playground/)'s Outputs view, the generated `dta.config.ts` and the commands that give the same files with the CLI.

## When to use

- At the end of something tried in the browser that a project can repeat with the CLI.
- Not for one command on its own: that is a [Command button](/design-system/components/command-button/).

<Examples component="cli-handoff" />

## Guidelines

- The config is one file row like an [output file](/design-system/components/output-files/), with Copy and Download.
- Each step's command is the site's [command chip](/design-system/components/command-button/); here it may wrap, so it never runs past a phone screen. Paths break after `/` or `.`.
- Commands read `npx design-token-authority …`, never `npx dta` (that npm name belongs to another package).
- A note under the steps says what they assume, such as the package installed in the project.
