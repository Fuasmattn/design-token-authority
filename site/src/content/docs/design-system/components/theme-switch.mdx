Switches the whole page between Light and Graphite. The choice is shared with the docs (Starlight's `starlight-theme`) and sets `data-brand` on the root, which selects the theme file DTA built.

<Examples component="theme-switch" />

## Guidelines

- A segmented control: two buttons in a group, the active one `aria-pressed`, each `size-target` tall.
- One per page, in the header next to the navigation.
- It switches the whole page, the examples here included.
