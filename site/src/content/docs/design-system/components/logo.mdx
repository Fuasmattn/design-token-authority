## Guidelines

- Once per page, top left. The mark alone is decorative; the link is named "dta, home".
- The filled square moves onto the outlined one on hover (`motion.duration.slow`, `motion.ease.standard`): a token changing a component. Reduced motion turns it off.

## The mark as a file

The mark alone, as an SVG, from `site/src/lib/brand-mark.ts`: the same drawing as the favicon, coloured by the tokens (`blueprint.600` for the square, `border.strong` of the theme for the outline).

- `/favicon.svg`: the light theme.
- `/brand/dta-mark-light.svg` and `/brand/dta-mark-dark.svg`: for light and dark backgrounds. The `dta diff` comment in pull requests shows them in front of its headline, chosen by GitHub's theme. Keep these URLs stable: comments already posted load them.
