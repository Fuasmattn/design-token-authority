## Guidelines

- Once per page, top left. The mark alone is decorative; the link is named "dta, home".
- On hover the filled square moves onto the outlined one (`motion.duration.slow`, `motion.ease.standard`); off under reduced motion.

## The mark as a file

The mark alone as SVG, drawn from the tokens (`site/src/lib/brand-mark.ts`):

- `/favicon.svg`: the light theme.
- `/brand/dta-mark-light.svg` and `/brand/dta-mark-dark.svg`: used by the `dta diff` pull-request comment. Keep these URLs stable: posted comments load them.
