A small mono label for state and context: info, neutral, changed, and the [status colours](/design-system/status-colours/) pass, warning and error.

<Examples component="chip" />

## Guidelines

- `meta`-sized mono, lower case, values after a middle dot: "changed · 4.2%".
- State chips carry a marker so colour is never the only cue: a dot (changed, pass), an open ring (warning), a filled square (error).
- Counts of findings are status chips (`3 errors`); a change is `changed`, never a status.
- Info and neutral are context and carry no marker.
- Chips are not buttons; a toggle filter is a segmented control.
