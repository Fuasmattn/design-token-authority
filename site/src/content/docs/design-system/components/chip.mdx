A small mono label for state and context: info (`action-subtle`), changed (`signal-subtle`), and the [status colours](/design-system/status-colours/): pass (`status-success-subtle`), warning (`status-warning-subtle`) and error (`status-error-subtle`).

<Examples component="chip" />

## Guidelines

- Text is `meta`-sized mono, lower case, values after a middle dot: "changed · 4.2%".
- State chips carry a marker so the state is not told by colour alone: a dot for changed and pass, an open ring for a warning, a filled square for an error (the shapes of the [severity markers](/design-system/#patterns)). Text in the tone's text colour on its tint (7:1), the status markers in `status-*-marker`.
- Counts of findings are status chips (`3 errors`, `2 warnings`, `0 findings`); something that changed is `changed`, never a status (and an error is never `changed`).
- Chips are not buttons; a filter that toggles is a segmented control.
