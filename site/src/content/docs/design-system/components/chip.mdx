A small mono label for state and context: info (`action-subtle`), changed (`signal-subtle`) and pass (`success-subtle`).

<Examples component="chip" />

## Guidelines

- Text is `meta`-sized mono, lower case, values after a middle dot: "changed · 4.2%".
- State chips carry a dot so the state is not told by colour alone.
- Chips are not buttons; a filter that toggles is a segmented control.
