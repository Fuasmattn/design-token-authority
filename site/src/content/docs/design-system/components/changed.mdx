A short value that lights up briefly when it changes, so nobody misses it: the counts of the playground's [Summary line](/design-system/components/summary-line/) and [Tabs](/design-system/components/tabs/).

## When to use

- Around a short inline value that changes while the visitor looks elsewhere: a count, a size, a status word.
- Not for rows or blocks, errors, or things that did not change.

<Examples component="changed" />

## Guidelines

- Only after a change: the first render is plain; each new value restarts the highlight.
- `action-subtle` ground, `action-text` ink, `radius-sm`; fades back over `motion.duration.highlight`. Never `signal` (that means "changed in a diff").
- The text never moves: the tint's padding is taken back by a negative margin.
- Stays under reduced motion: it is colour, not movement, and carries information.
