An action or a link shown only as an icon. The site header uses two, for the GitHub repository and the npm package, next to the [theme switch](/design-system/components/theme-switch/) (in the [Nav](/design-system/components/nav/)'s row, at the bottom of its menu on phones). The [Detail panel](/design-system/components/detail-panel/)'s close button is one too.

## When to use

- For a destination everyone recognises by its mark (GitHub, npm), or an action everyone recognises by its glyph (close), where a word would only take room.
- Not for actions that need a word to be understood: use a [Button](/design-system/components/button/).

## Guidelines

- A circle of `size-target` (44px, a full touch target) around a glyph of `size-icon` (20px) in `fg-default`. At rest only the icon shows; hover fills the circle with `bg-hover`, keyboard focus adds the focus ring (`stroke-focus` in `action-subtle`). No border, no shadow. The Nav's menu button looks and behaves the same.
- `label` is required: it is the accessible name and the tooltip ("GitHub repository", "npm package"). The icon is hidden from assistive tech.
- Icons live in `icons.ts`, one path each, in `currentColor`: the services' official marks (one-colour use is allowed by the brands) and plain glyphs (close). Add one there before using it.
- With `href` it is a link, otherwise a button. External links open in the same tab.
- The styles live in `IconButton.css` (global class `dta-icon-button`), so a Preact island renders the same button: the [Detail panel](/design-system/components/detail-panel/) does for its close button.
