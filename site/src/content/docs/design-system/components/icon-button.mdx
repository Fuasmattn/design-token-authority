An action or link shown only as an icon: GitHub and npm in the site header ([Nav](/design-system/components/nav/)), and the [Detail panel](/design-system/components/detail-panel/)'s close button.

## When to use

- For a destination or action everyone recognises by its mark or glyph (GitHub, npm, close).
- Not for actions that need a word to be understood: use a [Button](/design-system/components/button/).

<Examples component="icon-button" />

## Guidelines

- A `size-target` (44px) circle around a `size-icon` (20px) glyph in `fg-default`. At rest only the icon; hover fills the circle with `bg-hover`; keyboard focus adds the `stroke-focus` ring in `action-subtle`. No border, no shadow.
- `label` is required: the accessible name and tooltip ("GitHub repository"). The icon is hidden from assistive tech.
- Icons live in `icons.ts`, one path each in `currentColor`; add one there before using it.
- With `href` a link (same tab), otherwise a button.
- Preact islands use the same styles: `IconButton.css`, class `dta-icon-button`.
