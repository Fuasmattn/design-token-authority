Chooses which mode of each multi-mode collection (brand, breakpoint) the [playground](/playground/)'s dependency graph shows.

## When to use

- Above a view that shows one mode of several: the [Graph canvas](/design-system/components/graph-canvas/) and [Graph list](/design-system/components/graph-list/).
- Not for choosing a view ([Tabs](/design-system/components/tabs/)) or options that combine ([Output options](/design-system/components/output-options/)).

<Examples component="graph-switcher" />

## Guidelines

- **Desktop:** a mono label over a `bg-subtle` well of `aria-pressed` buttons (at least 44 px) in a labelled group; the selected mode on `bg-surface` in a 2 px ink outline. The label sits above, so the row stays one line when the detail panel opens.
- **Phones (up to 760 px):** native `<select>`s in a 2 px ink box, so the phone's own picker opens.
- A mode with findings shows their count with marker and word in the [status colours](/design-system/status-colours/); inside a select option, as text.
- **The note** below says what is in view (counts, findings in this view) and how to move; `narrowNote` replaces it on phones.
- **Motion:** a pressed option tints over `motion.duration.fast`; the graph crossfades (`dta-tabs`). At once under reduced motion ([Motion](/design-system/motion/)).
