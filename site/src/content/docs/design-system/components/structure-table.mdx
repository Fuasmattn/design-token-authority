The collections of a token set as `dta analyze` reports them: modes, layer role and confidence, variable count and share of aliases. Used in the [playground](/playground/)'s Structure view.

## When to use

- Wherever a token set has been read and its structure should be shown.
- Selectable when each collection has more to show (its tokens); plain in documentation.

<Examples component="structure-table" />

## Guidelines

- Rules and type, no card: a 2 px ink rule under the mono header, hairlines between rows. Names, modes and numbers in mono; modes as small `bg-subtle` labels.
- Low confidence (the one `dta analyze` marks with ⚠) gets "⚠ review" in `status-warning-text`: a word, never colour alone, never `signal` ([Status colours](/design-system/status-colours/)).
- Below 640 px of container each collection becomes a short labelled list; table roles stay for screen readers.
- Brands (the brand collection's modes) go under the table.
- **Selectable rows** (`onSelect`): the name is a button with `›`, the whole row its hit area; it opens the [Detail panel](/design-system/components/detail-panel/). The open row has `aria-current` and `action-subtle` (text `action-text`); hover `bg-subtle`. `hideCaption` keeps the caption for screen readers only.
- **Motion:** the selection tint fades over `motion.duration.fast`; instant under reduced motion.
