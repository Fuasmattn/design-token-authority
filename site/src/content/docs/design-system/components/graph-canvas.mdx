The token dependency graph of the [playground](/playground/)'s Graph view: one column per layer, every token a row, an arrow from each alias to the token it uses.

## When to use

- To see how tokens depend on each other across layers, and where a chain breaks.
- On desktop only; on phones (below 760 px) the same data is the [Graph list](/design-system/components/graph-list/).

## Guidelines

- **Rows, not cards:** a 1 px `border-strong` outline on `bg-surface`, `radius-sm`; the leaf name, then the value (a swatch for colours) or `· unused` in `fg-subtle`. No shadows.
- **Headers:** collection, mode and token count over a 2 px ink rule. A finding about the layer's file sits on the header as a button that opens it in the Lint view.
- **Arrows:** hairline curves in `fg-subtle` with a filled head; an alias into its own column arcs on the right.
- **Findings keep shape, word and colour** ([Status colours](/design-system/status-colours/)): an error row on `status-error-subtle` in a 2 px `status-error-marker` outline with the filled square and "error"; a warning with the open ring and "warn". A circular pair gets error arcs and a "circular" chip; a dangling alias a dashed arrow to a dashed "missing" row. Never `signal`.
- **Selection is blueprint:** the selected row and its alias chain on `action-subtle` in a 2 px `action-bg` outline, text in `action-text`, arrows in `action-bg`. A selected finding keeps its marker and word.
- **Keyboard:** one row in the tab order (roving `tabindex`). ↑/↓ within a column, ← to the token it uses, → back to a token that uses it, Home/End to the column's ends, Enter or Space selects. The accessible name is the full token name, its value, what it uses and why it doesn't resolve.
- **Size:** fixed width (716 px, fits beside the detail panel at 1280); a narrower box scrolls inside itself, never the page. `reveal` scrolls a selection made elsewhere into view.
- **Legend** under the drawing: alias arrow, selected chain, error, warning, unused.
- **Motion:** tints change over `motion.duration.fast`; hover tints at once. Under reduced motion the highlight is immediate and the scroll jumps ([Motion](/design-system/motion/)).
