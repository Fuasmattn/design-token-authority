A copyable CLI command on `terminal-bg`: every command on the site, and in its large size the landing page's call to action.

<Examples component="command-button" />

## Guidelines

- The `$` prompt in `terminal-prompt`, the command in mono, a copy icon at the end.
- Clicking copies the command without the `$`; the icon turns into a tick for 1.6 s and "copied" is announced ("select to copy" without a clipboard).
- Accessible name: "Copy: " and the command.
- Two sizes: default and large (hero and final call).
- At most one outline Button beside it. No blinking caret.
- In a Preact island use the classes from `CommandButton.css` (`dta-command` …).
