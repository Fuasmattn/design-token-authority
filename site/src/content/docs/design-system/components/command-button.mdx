A copyable CLI command on `terminal-bg`: the main call to action wherever DTA can be started from the terminal.

<Examples component="command-button" />

## Guidelines

- Shows the `$` prompt in `terminal-prompt`, the command in mono and a small "copy" hint.
- Clicking copies the command without the `$` and swaps the hint to "copied" for a moment (announced to screen readers).
- Its accessible name names the command.
- Pair it with one outline Button at most.
