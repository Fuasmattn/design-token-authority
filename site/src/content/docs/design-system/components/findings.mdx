Findings worded as the CLI prints them: input diagnostics as `error [code] message (file)` (`formatDiagnostic` in `@dta/core`), lint violations as `warn message [rule]` grouped by file, then the summary line `dta lint` ends with (`formatLintSummary` and `LINT_MESSAGES` in `@dta/lint`). In the [playground](/playground/)'s Lint view the same lines are grouped by rule, summaries first: one row per rule with its count (`groupViolationsByRule` and `formatRuleCount` in `@dta/lint`; the built-in rules are listed also when clean), and a rule with findings opens to its lines.

## When to use

- Grouped by file (titled groups) for input diagnostics and a report you read top to bottom, as `dta lint` prints it.
- Grouped by rule (groups with a `count`) where the overview matters more than every line: a workspace view. With `onSelect` each line opens its details in the [Detail panel](/design-system/components/detail-panel/).

## Guidelines

- Mono lines in the page's ink, not a terminal: the findings are read, not run.
- Severity is the word plus a marker shape: errors a filled square, warnings an open ring. The design system has no error colour and `signal` is never used for errors, so nothing here is red.
- A clean result shows the pass dot and its line in `success-fg`.
- **Rule rows:** mono, 48 px tall, the rule's marker (its worst severity; none for a clean rule), the rule id, its count in `fg-muted`, and a `›` that turns when open. A native disclosure (`details`/`summary`), so it works without script; a rule without findings is a plain row.
- **Selectable lines:** the whole line is a button (at least 44 px), with the file as a quieter second line. The open one is marked with `aria-current` and tinted `action-subtle`; its marker and words turn `action-text`, never a colour of their own.
- Long names and messages wrap anywhere; a list never scrolls sideways on a phone.
- **Motion:** a rule's lines open and close by animating their height (`::details-content` with `interpolate-size`, `motion.duration.base`; no script measures them, browsers without it open at once), the chevron turns, and a selected line's tint comes and goes over `fast`. Static under reduced motion. See [Motion](/design-system/motion/).
