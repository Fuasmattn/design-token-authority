Diagnostics and lint findings worded as the CLI prints them, grouped by file or by rule, with the summary line; used in the [playground](/playground/)'s Lint view.

## When to use

- Grouped by file for input diagnostics and a report read top to bottom.
- Grouped by rule (with counts) for a workspace view; with `onSelect` each line opens the [Detail panel](/design-system/components/detail-panel/).

## Guidelines

- Mono lines in the page's ink, not a terminal.
- Severity is word plus marker shape, in the [status colours](/design-system/status-colours/): error a filled square in `status-error-marker`, warning an open ring in `status-warning-marker`; the word in `status-*-text`, the rest of the line in the ink. Never `signal` for errors or warnings.
- The summary line takes its outcome's colours; a clean result shows the pass dot in `status-success-marker` and `status-success-text`.
- **Status banner** (`banner` with an `outcome`) only for what stops the work (unreadable input, a failed build): the list on `status-error-subtle` in a complete 2 px outline in the marker colour, every line in the status text. Not for a lint view.
- **Rule rows:** a native disclosure (`details`/`summary`), 48 px tall, with the rule's worst marker, the id, the count (`fg-muted` for `no findings`) and a chevron. A clean rule is a plain row.
- **Selectable lines** are buttons at least 44 px tall, the file as a quieter second line; the open one has `aria-current`.
- **Selection and severity at once:** selection is the `action-subtle` tint with text and file in `action-text`; the marker and word keep their status colours (markers ≥ 3:1, words ≥ 7:1 on the tint).
- The selected line is never hidden: moving the selection into a closed rule opens it; a rule the visitor opened is never closed. With `idPrefix` each line has an id, so focus can return to it.
- A diagnostic that points to the docs ends with a link to the page (`action-text`, underlined); not on selectable lines.
- Paths break after `/` or `.` and keep segments whole ([Token path](/design-system/components/token-path/)); a list never scrolls sideways on a phone.
- **Motion:** a rule opens by animating its height (`motion.duration.base`), a selection tint over `fast`; static under reduced motion ([Motion](/design-system/motion/)).
