Four variants for actions: primary (`action-bg`), outline (`border-strong`), quiet (hairline, no fill) and link.

<Examples component="button" />

## Guidelines

- One primary per view; outline for the secondary action, link for tertiary. A link that only goes to another page is an [Arrow link](/design-system/components/arrow-link/), not a button.
- Quiet for the small action repeated on every row (Copy, Download); its border turns `border-strong` on hover.
- At least 48 px tall (44 px minimum on touch), `radius-md`, the `label` text style.
- Focus is a `stroke-focus` ring in `action-subtle`, never only a colour change.
- Labels are verbs: "See a review", not "Click here".
- With `href` it is a link, otherwise a `<button>`.
- In a Preact island use the classes from `Button.css` (`dta-button` plus the variant), never a look of its own.
