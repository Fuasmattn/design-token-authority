Renders token paths, alias ids and file paths so a line breaks between segments, never inside one: `Brand(Alias).BrandA/Colors/Surface/Muted` never wraps as "Surface/Mu" + "ted".

## When to use

- Everywhere a path can wrap: token names, alias ids, token and output files, commands with a file.
- In prose that contains paths: the helper finds them and leaves the rest alone.
- Not for code shown as it is: that keeps its lines and scrolls ([Detail panel](/design-system/components/detail-panel/)).

<Examples component="token-path" />

## Guidelines

- **One helper:** `breakPaths(text)` in `TokenPath.tsx` adds `<wbr>` after each separator; `<TokenPath path="…" />` renders a standalone path in mono. Findings, Detail panel, Output files, Source bar and CLI hand-off all use it.
- **Breaks** after a `/` between characters, after a `.` that follows a letter or `)`, or a digit before a letter. **Never** in a decimal (`0.94`), before a space, in `...` or next to another `/`.
- Keep `overflow-wrap: anywhere` as the last resort for a single segment longer than the line.
- `<wbr>` is not text: screen readers and copying are unaffected.
