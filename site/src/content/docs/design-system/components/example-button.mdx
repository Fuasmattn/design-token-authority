## Guidelines

- Reads only the example's variables (`--colors-brand-primary`, `--colors-text-on-primary`, `--radius-card`), built with DTA from `site/examples/orbit-burger` and scoped under `[data-example="orbit-burger"][data-state]`. Nothing of the page's own palette, so it reads as a customer's component.
