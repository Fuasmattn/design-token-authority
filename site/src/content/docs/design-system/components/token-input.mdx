How token files get into the [playground](/playground/) before anything is loaded: a drop area that takes the page and is also a button, the examples, and a paste field.

## When to use

- As the whole page of a tool that needs input first.
- Not once something is loaded: then the [Source bar](/design-system/components/source-bar/) takes over.

<Examples component="token-input" />

## Guidelines

- **Drop area:** dashed ink outline on `bg-surface`, about 40 % of the screen (at least 220 px). Hover and focus turn it `action-bg`; dragging files over fills it with `action-subtle`. A button that opens the file picker, so keyboard and phones work; several files at once.
- Label "Drop token files" then "or choose files" in `action-text`, underlined; a help line says what it accepts.
- **Examples:** outline [Buttons](/design-system/components/button/) in one column, what each loads beside it in mono `fg-subtle` (`aria-describedby`). Below 560 px the description goes under its button. Bundled with the page, so loading one needs no request.
- **Paste:** "Paste JSON instead" (link button) swaps the drop area for a mono textarea labelled like a [Text field](/design-system/components/text-field/); the button then says "Choose files instead"; focus moves to the field or back. A pasted per-mode file needs a `{Collection}.{Mode}.json` name; "Check pasted JSON" is the one primary action.
- It only reads files (`{ fileName, content }`); the playground interprets them. Input that cannot be read shows as an error banner from [Findings](/design-system/components/findings/), not in the input.
- **Motion:** view-transition part `dta-source`: loading collapses it into the Source bar; drop area and paste field crossfade; hover and drag states over `motion.duration.fast`.
