## Guidelines

- Station states: done (`success-fg`), active (`action-bg` with an `action-subtle` halo), next (`border-strong` outline), review (`signal-bg` outline on `signal-subtle`). Each state is also written out for screen readers.
- Each station has a mono number and a short label; add the actor below ("Designer, in Figma") when space allows.
- Below 760px: two columns, rail and packet hidden.
- The packet loop is 7.2s linear and stops under reduced motion.
