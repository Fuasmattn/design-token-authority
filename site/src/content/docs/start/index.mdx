DTA is a command-line tool for design tokens. It takes your tokens from Figma (or plain [DTCG](https://tr.designtokens.org/format/) JSON files), checks them, builds them for every platform and shows what a change does to your UI before it ships. Same input, same result: on your machine, in CI or in an agent.

## Why

When tokens change every week:

- **Structure drifts.** Naming and layers break, and nobody notices.
- **Code breaks quietly.** A renamed token is still used somewhere.
- **Screenshots pile up.** One colour change touches a hundred screens.

DTA turns each change into one review: the token changes, the lint findings and the screenshots, grouped by the token that caused them.

## What it does

| Command     | Does                                              |
| ----------- | ------------------------------------------------- |
| `dta init`  | Sets up a project                                 |
| `dta pull`  | Figma variables to token files                    |
| `dta push`  | Token files back to Figma (never deletes)         |
| `dta build` | CSS, JavaScript, Tailwind, Swift, Android         |
| `dta lint`  | Structure checks                                  |
| `dta diff`  | Token changes and screenshots, explained by token |

All commands: [Commands](/reference/commands/). No install yet? Try the [playground](/playground/): it runs in your browser and uploads nothing.
