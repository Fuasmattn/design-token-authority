You need Node.js 24.22.1 or newer and a project with a `package.json`. Not on a Figma Enterprise plan? Export your variables with a plugin first; the wizard asks for the file ([Getting tokens out of Figma](/guides/figma/)).

```sh
npm create dta
```

Installs DTA in your project, writes `dta.config.ts` and offers to set up review of UI changes in pull requests, pull your tokens and build them.

## Then

```sh
npx dta pull
```

Gets the latest variables from Figma ([`dta pull`](/reference/commands/#dta-pull)).

```sh
npx dta build
```

Builds CSS, Tailwind, JS or native code from your tokens ([Outputs](/reference/outputs/)).

```sh
npx dta lint
```

Checks the structure: broken aliases and the rules you turn on ([Lint rules](/reference/lint-rules/)).

```sh
npx dta diff
```

Shows what changed against your main branch ([dta diff in pull requests](/guides/dta-diff-in-pull-requests/)).
