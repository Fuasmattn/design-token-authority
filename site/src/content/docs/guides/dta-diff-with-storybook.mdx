title: dta diff with Storybook
description: Screenshot every story of a static Storybook build and explain the changes by token.
---

Screenshot every story of your Storybook build, each on its own. `dta init --diff` finds Storybook and writes this setup for you ([Before you start](/guides/dta-diff-in-pull-requests/#before-you-start)).

## Configure

```ts title="dta.config.ts"
diff: {
  build: 'npx dta build && npm run build-storybook',
  outDir: 'storybook-static',
  stories: { type: 'storybook' },
  viewports: [1280, 390],
}
```

```sh
npx dta diff --list
```

Lists the stories it would render, after one build.

- Needs Storybook 7 or later (`index.json`).
- The base is built in a fresh checkout and installed on its own; set `diff.setup` only if that doesn't fit.

## Which stories

Docs pages are left out. To leave out a story, tag it **`skip-dta-diff`**:

```js title="Button.stories.js"
export const Playground = { tags: ['skip-dta-diff'] }
```

Other tags or story ids:

```ts
stories: {
  type: 'storybook',
  excludeTags: ['skip-dta-diff', 'experimental'],
  exclude: ['^internal-'], // story ids, as regular expressions
},
```

## How changes are explained

Your stories must use the tokens as CSS custom properties: import the CSS `dta build` writes in `.storybook/preview.js`.

```js title=".storybook/preview.js"
import '../output/css/variables.css'
import '../output/css/themes/branda.css'
```

Your own CSS may re-declare the variables (a theme scoped to a wrapper, inside `@media` or `@layer`): those changes are explained too.

Values baked in as literals (a Tailwind config with resolved colours, JavaScript reading token values, inline `style` attributes) can't be traced to a token: those pixels show as **unexplained**.
