How to keep a coding agent (Claude Code, Codex, Cursor) from inventing colours and token names. Agents propose; `dta push` stays a person's job.

## 1. Install the skill

```sh
npx dta skill add
```

Writes `.claude/skills/dta/SKILL.md`: the workflow, the rules and every command. `--dir` for agents that read skills elsewhere; `--check` in CI fails when it is out of date.

## 2. Generate the project context

```sh
npx dta context
```

Writes `DESIGN.md` (brands, collections and the tokens to use, with their CSS and Tailwind names) and a short block in `AGENTS.md` pointing to it; the rest of `AGENTS.md` stays yours. `--check` fails when they are out of date. Add `context: {}` to the config and `dta build` keeps them current ([Configuration](/reference/configuration/#context)).

## 3. Look tokens up

```sh
npx dta token find '#003f8a'
```

The tokens that resolve to a value, semantic ones first.

```sh
npx dta token get Colors.Brand.Primary
```

A token's value per brand, its alias chain and its CSS and Tailwind names. Both take `--format json` ([Token queries](/reference/token-queries/)).

## 4. Check the code it wrote

```sh
npx dta audit
```

Lists hard-coded values that equal a token, and exits with 1 when it finds any. A deliberate value gets a `dta-audit-ignore` comment. In an existing codebase, record today's findings first with `--update-baseline` ([CI with GitHub Actions](/guides/ci/#hard-coded-values-in-code)).

## The loop

What the skill asks of the agent when it changes token files:

1. Edit the token files, never the build output.
2. `dta lint`: exit code 2 means errors to fix.
3. `dta build`.
4. `dta diff --tokens-only --format markdown`: what changed and what depends on it.
5. Fix and repeat. Then a person reviews and pushes to Figma.

## Briefs for AI design tools

Tools without a terminal (Stitch, v0, a chat) get a short brief per brand to paste into the prompt: colours with their roles, fonts, sizes, spacing, radii and rules.

```sh
npx dta brief --brand BrandA
```

`--copy` puts it on the clipboard, `--format json` gives it as data. Add the brand's character and your own rules in the config:

```ts title="dta.config.ts"
brief: {
  identity: 'Calm, trustworthy, institutional.',
  rules: ['Never use pure black: use Colors.Text.Default.'],
},
```

For tools that can only read files: [`/llms.txt`](/llms.txt) and the [JSON Schemas](/reference/#schemas).
