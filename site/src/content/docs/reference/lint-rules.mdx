`dta lint` checks the token files in `tokens.dir`. A rule reports **errors** (exit code 2) or **warnings** (exit code 0, printed). `dta push` runs the same check before it changes Figma (`--skip-lint` skips it).

## Always on

| Rule                    | Severity | Finds                                                   |
| ----------------------- | -------- | ------------------------------------------------------- |
| `no-dangling-aliases`   | error    | An alias whose target does not exist                    |
| `no-circular-aliases`   | error    | Aliases that point at each other in a circle            |
| `no-default-mode-names` | error    | Modes still called `Mode 1`, `Mode 2` (Figma's default) |

One finding of each, on the `brand-ab-problems` fixture (the brand-ab tokens with three flaws; it is the [playground](/playground/)'s "Example with problems", which shows the same findings in your browser):

```txt title="dta lint (test/fixtures/brand-ab-problems)"
|  Brand(Alias).BrandB.json
|
|    error Alias {Colors.Foundation.Orange.550} references non-existent token "Colors.Foundation.Orange.550" [no-dangling-aliases]
|
|  (unknown file)
|
|    error Circular alias chain: Brand(Alias).BrandA/Colors/Surface/Muted → Brand(Alias).BrandA/Colors/Text/Muted → Brand(Alias).BrandA/Colors/Surface/Muted [no-circular-aliases]
|
|  Primitives.Mode 1.json
|
|    error Mode name "Mode 1" is a Figma default — rename to something meaningful [no-default-mode-names]
|
|
|  3 errors found.
|
—  Lint failed.
```

### Broken aliases fail the build

A dangling or a circular alias has no value, so `dta build` fails on the first two rules too: it prints the same message as `dta lint` (one error per alias and per cycle), writes no file at all and exits with 1. Files from an earlier build stay as they were, so the output folder is never half rebuilt. Fix the alias, then build again. On the same fixture:

```txt title="dta build (test/fixtures/brand-ab-problems)"
x  error [dangling-alias] Alias {Colors.Foundation.Orange.550} references non-existent token "Colors.Foundation.Orange.550". See site/src/content/docs/reference/lint-rules.mdx. (Brand(Alias).BrandB.json)
|
x  error [circular-alias] Circular alias chain: Brand(Alias).BrandA/Colors/Surface/Muted → Brand(Alias).BrandA/Colors/Text/Muted → Brand(Alias).BrandA/Colors/Surface/Muted. See site/src/content/docs/reference/lint-rules.mdx. (Brand(Alias).BrandA.json)
|
|  Nothing was written: fix the errors above and build again.
|
—  Build failed.
```

The playground's Outputs view shows these errors instead of files. A default mode name does not stop the build.

## Configurable

Configured under `lint.rules`. A configured rule is a warning unless you set `severity: 'error'`; `'off'` disables it.

```ts title="dta.config.ts (the brand-ab fixture)"
lint: {
  rules: {
    'semantic-must-alias': { severity: 'error', collections: ['Brand(Alias)', 'ScreenType'] },
    'naming-pattern': { severity: 'warn', patterns: { 'Brand(Alias)': '^[A-Z][A-Za-z ]*$' } },
    'color-contrast': {
      severity: 'warn',
      minRatio: 4.5,
      pairs: [
        ['Colors.Text.Default', 'Colors.Surface.Default'],
        ['Colors.Text.On Primary', 'Colors.Brand.Primary'],
      ],
    },
    'no-duplicate-values': { severity: 'warn' },
  },
},
```

### `semantic-must-alias`

Every token in the listed `collections` must be an alias. Catches a semantic or brand token that holds a raw value and would no longer follow the palette.

```text
Token has a raw value "#ffffff" but should be an alias in collection "Brand(Alias)"
```

### `naming-pattern`

`patterns` maps a collection name to a regular expression; every segment of every token path in that collection must match it. An invalid expression is a config error.

```text
warn Token path segment "overlay" does not match pattern /^[A-Z][A-Za-z ]*$/ for collection "Brand(Alias)" [naming-pattern]
```

### `color-contrast`

For each `[foreground, background]` pair, the WCAG contrast ratio must reach `minRatio` (default 4.5, level AA). Token names are written with dots or slashes.

Limits of the current version: only tokens that hold a raw hex colour are compared (an alias is skipped), and when several modes define the same name, the last one read wins, so it does not check each brand separately.

### `no-duplicate-values`

Reports raw values that appear more than once, across all collections and modes: a hint that one of them could be an alias.

```text
warn Duplicate value "8" — also defined in: Primitives.Value/Dimensions/spacing/2 [no-duplicate-values]
```

## `--fix`

`dta lint --fix` is accepted but has no fixes yet; it says so and lints as usual.
