Look tokens up without reading the JSON: what a token resolves to, which token has a value, which tokens exist. Reads `tokens.dir`, changes nothing. Every option: [Commands](/reference/commands/#dta-token-get).

## dta token get

A token's value and alias chain per brand or mode, and its names in code.

```text
$ dta token get Colors.Brand.Primary
Colors.Brand.Primary  color · Brand(Alias)

  BrandA  #0057b8  Colors.Brand.Primary → Colors.Foundation.Blue.500
  BrandB  #3d5a80  Colors.Brand.Primary → Colors.Foundation.Navy.500

  CSS       var(--colors-brand-primary)
  Tailwind  --color-brand-primary
```

- `--mode Brand=BrandB` reads one mode only; repeat it to pick a combination (`--mode theme=dark --mode brand=b`).
- An unknown name exits with 1 and lists the closest names.

## dta token find

Every token that resolves to a value. The first line is usually the one to use: tokens the build writes come first, aliases before primitives.

```text
$ dta token find '#003f8a'
2 tokens resolve to #003f8a:

  Colors.Brand.Primary Dark   BrandA      var(--colors-brand-primary-dark)
  Colors.Foundation.Blue.700  every mode  var(--colors-foundation-blue-700)
```

- Colours match in any notation and colour space; `--near` also matches within about 2 % per channel.
- Numbers with or without `px`, dimensions and durations with their unit (`0.2s` finds `200ms`).
- `--type` limits the search to one token type. No match exits with 1.
- With `breakpoints` in the config, tokens that have the value at every screen width come first; a token that has it only at some widths shows its media query. `dta audit` ranks the same way.

## dta token list

Names with type and collection. Filter with `--collection`, `--type` and `--match` (a glob: `*` within a segment, `**` across).

```text
$ dta token list --match 'Colors.Text.*'
Colors.Text.Default     color  Brand(Alias)  (alias)
Colors.Text.Muted       color  Brand(Alias)  (alias)
Colors.Text.On Primary  color  Brand(Alias)  (alias)

3 tokens.
```

## JSON output

`--format json` prints one object with `"schema": "dta.token/1"` and a `kind`: `token`, `unknown` (with `suggestions`), `matches` or `list`. Schema: [`/schemas/dta.token.schema.json`](/schemas/dta.token.schema.json). `code` is missing for a token the build doesn't write.
