## The examples are real projects

Every example token set on these pages is a folder in the repository, [`site/learn-examples/`](https://github.com/Fuasmattn/design-token-authority/tree/main/site/learn-examples), with a `dta.config.ts` and a `tokens/` folder. The files on the pages are imported from there, and a test runs `dta lint` and `dta build` on each of them, so what you read is what the CLI accepts. To try one, run DTA from a clone (see [Quick start](/start/quick-start/)) inside the folder:

```sh
cd site/learn-examples/tiers
dta lint && dta build   # writes output/ next to tokens/
```

Where the DTCG specification and DTA differ, the pages say so and show the spec's syntax separately, marked as not read by DTA yet.
