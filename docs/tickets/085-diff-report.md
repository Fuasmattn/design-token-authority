## What to build

`dta diff` writes `report/index.html`: grouped by token change with representative samples and a contact sheet, unexplained changes one by one, each with baseline, candidate, diff overlay and drag-to-compare slider, redline labels naming tokens; plus `summary.md` and PNGs. Static, opens from disk.

## Acceptance criteria

- [x] Uses the Drafting Table tokens built by DTA (same source as the website)
- [x] Portable: one self-contained folder, relative links only, works from disk or any static host; keyboard-accessible slider; light and Graphite
- [x] `summary.md` fits a PR comment (table per story × viewport, ratios, cause)
- [x] Report rendering tested from a fixed result
- [x] All gates pass, and the GitHub run is green

## Notes

- `renderReportHtml(result)` in `@dta/visual-diff` (`src/report/html.ts`), rendered from the parsed `result.json`; the CLI writes `index.html` into the report folder and prints its path.
- Tokens: `src/report/tokens-css.ts` is generated by DTA from `site/tokens` (`pnpm report:tokens`, `site/scripts/report-tokens.ts`); `site/report-tokens.test.ts` fails when it is stale. The file is excluded from Prettier (generated).
- Attribution now also records `regions` (up to five dependent boxes per token) and `canvas`, so the report can place redline labels on the elements (additive fields in `dta.diff/1`).
- `summary.md` via `renderSummaryMarkdown`: under 60,000 characters, tables cut with "… and N more".
- No font files in the report: the token font stacks fall back to system fonts, which keeps the folder small and offline.
- Checked by screenshots from disk (`file://`) at 1280 px (light and Graphite) and 390 px (no horizontal scroll) on a dogfood run with two token changes and one component change.
- Known limit, documented in the package README: a component change inside an element that a changed token also restyles or moves counts as explained (the Chip radius change next to `space.2` in the dogfood run).
