# TICKET-101: `dta skill add`: the DTA skill for coding agents

**Phase:** 9 — Agent interop
**Priority:** High
**Effort:** S
**Blocked by:** 100
**Status:** done
**Spec:** [agent-interop](../specs/agent-interop.md) (decision 3, settled question 1)

## What to build

`dta skill add [--dir <path>] [--check]` writes `SKILL.md` (Agent Skills format: `name`, `description` front matter) to `.claude/skills/dta/` by default.

Content, short and imperative: DTA in one paragraph; the loop (change tokens → `dta lint` → `dta build` → `dta diff --tokens-only` or `dta diff` → read the result → fix → repeat); look tokens up before writing a value (`dta token find`, `dta token get`); the rules (semantic tokens in components, never raw values; never `dta push --yes`, a person pushes to Figma; never edit generated files); what the exit codes mean; where the project context is (`DESIGN.md`, TICKET-102).

## Acceptance criteria

- [x] The text is a template in `@dta/cli`, filled from `commandReference()`; a test parses every `dta …` command line in it and checks commands and options against the CLI
- [x] Header with the DTA version and a "generated" marker; `add` overwrites only a file with the marker (otherwise exits 2 and says so)
- [x] `--check` exits 1 when the installed skill differs from the current one
- [x] Snapshot scenario of the written file; all gates pass, and the GitHub run is green

## Outcome

- `packages/cli/src/skill/template.ts` renders `SKILL.md`; its command list is `commandReference()`. A test extracts every `` `dta …` `` span and checks the command and each option against the registry (it caught a mention of `dta context` before TICKET-102 exists; that mention comes back with 102).
- `dta skill add [--dir <path>] [--check]` needs no config. Marker: `<!-- Generated by \`dta skill add\` (DTA x.y.z) … -->`; a file without it is left alone (exit 2). `--check` compares byte for byte, so a new DTA version makes the skill stale until it is re-added.
- `packageVersion()` moved to `version.ts`. The snapshot normaliser replaces `(DTA x.y.z)` with `(DTA <version>)`, so a release does not change the `skill-add` snapshot.
