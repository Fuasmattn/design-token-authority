Only “after”, with the change marked

One panel, the full row wide, the story at 1:1. Each changed box is outlined in signal; the tokens that explain it are stacked notes under the story (a short leader when the box sits inside another). The table below says the same in body text: token, base and head values with swatches, which box.

“Show before” swaps in place

A toggle button (box, tick, the word on / off; aria-pressed; Enter and Space) shows the base image on the same spot, so flicking reveals a subtle step such as Nova 500 → 600 (1.38 : 1 apart). While “before” shows, the outline, leaders and notes are hidden but keep their space, and the label reads “Before · base”. Same height in both states: no layout shift.

Unexplained: overlay on, “Show before” beside it

The diff overlay (changed pixels in signal, the rest clear) is on by default and sits next to “Show before”; both are toggles of the same kind. A dashed outline and an outlined “unexplained · no token” label mark the region; no token notes. Explained rows have no overlay toggle by default (the outline already says where); the diff image stays one link away.

Slider and thumbnails go

“Show before” replaces the drag-to-compare slider: no seam, no drag, works by keyboard and on a phone without fighting the scroll. The three thumbnails go too; “Whole images: before · after · diff” under every row keeps the full PNGs one click away. Two images per row instead of six.

Phone 390: same model, full width

The story image runs edge to edge (390 px story at 1:1 on a 390 px screen), the two toggles share a row, each 44 px high. Notes take two lines (token, then change) so they stay inside the image; the token table becomes a list.

Marks keep a 1 px ink line

Signal alone is 2.98 : 1 (Light) and 2.14 : 1 (Graphite) on the light story page, under 3 : 1. Every outline, leader and note gets a 1 px ink line around it (14.15 : 1 on light stories); on dark surfaces such as the card the signal itself holds (4.91 / 6.85 : 1). Notes: colours name the alias step (Nova 500 → 600), sizes show resolved numbers (8 → 24).
